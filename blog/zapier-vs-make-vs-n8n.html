Deep Dive

Zapier: 6,000+ apps. AI by Zapier writes your zaps. Best if you want "it just works." Downside: expensive at scale.

Make (Integromat): Visual builder, see data flow. 40% cheaper. Better for multi-step AI workflows (e.g., scrape → ChatGPT → Sheets → email).

n8n: Open source. Host on £5 VPS = unlimited tasks. Steep learning but costs 80% less long-term. Full AI agent support.

3 Automation Recipes

  1. Lead capture: Typeform → ChatGPT (score lead) → HubSpot → Slack alert
  2. Support: Gmail "support@" → AI summary → Notion ticket → auto-reply
  3. Invoicing: Stripe payment → Make PDF → Xero → email client

All three platforms handle these. Make does it cheapest, Zapier fastest.

My Recommendation

Start with Make (£9/mo). If you hate visual builders, switch to Zapier. Move to n8n when you're spending £100+/mo.
